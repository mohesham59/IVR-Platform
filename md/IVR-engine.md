# IVR-engine Module

## Overview
The `IVR-engine` directory houses the core telephony backend. It acts as the bridge between the Asterisk PBX system and the VoiceXML (VXML) scenarios designed by the users.

## Technical Responsibilities
- **AGI Server:** Implements a FastAGI (Asterisk Gateway Interface) server that listens for incoming calls routed by Asterisk.
- **VXML Execution:** Parses the VXML documents generated by the frontend, interprets the nodes (menus, prompts, record, input), and dictates the flow of the call.
- **Media Management:** Resolves audio file paths for playback and interfaces with Asterisk to stream audio over SIP/RTP.
- **TTS Fallback:** Manages fallback mechanisms to Text-To-Speech (TTS) when pre-recorded audio is unavailable.
- **Call Analytics Tracking:** Logs call events, durations, and outcomes to the database for dashboard reporting.

## Architectural Flow
When a SIP call hits Asterisk, the dialplan routes it to the `IVR-engine` via FastAGI. The engine reads the associated VXML file from the local file system (or database), controls the Asterisk channel (answering, playing media, collecting DTMF digits), and ultimately terminates the call. It operates independently of the AI and web layers, focused strictly on telephony logic.
